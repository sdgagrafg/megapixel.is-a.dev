RumbleSound

Put your PS5 controller on the table, and the table plays your song.

Before you start: make DualSense Wireless Controller your Windows default sound output (press Win + Ctrl + V and pick it). Some browsers ignore the page's choice and always use the default output, so otherwise the song plays in your headphones instead of rumbling the controller. Switch back when you're done.

The browser will ask you to pick the controller. For the voice-vs-music slider, choose the “(DualSense stems)” file.

Settings
Lower = more voice, less background.
Help
  1. Open the page from its web address (https://…) in Chrome, Edge or Chromium on a computer. Opened as a file (file:///…), the browser hides the sound devices. Phones and Firefox/Safari can't talk to the controller.
  2. Connect the controller with a USB cable. Bluetooth can't send audio to the haptic motors.
  3. Song plays in your headphones/speakers instead of rumbling? Make DualSense Wireless Controller the Windows default output (Win + Ctrl + V), then reload this page. Switch back afterwards.
  4. If the controller doesn't show up in the box, close DS4Windows or DSX and replug the cable. Steam can stay open.
  5. Put the controller in the middle of a hard table. A hollow wooden surface or an upside-down box is louder.
  6. Pick it up to pause, and put it down to continue. If it starts turning or walking, tilting or falling, the sound stops automatically.
  7. If it says "only 2 channels": Windows sound settings → More sound settings → Playback → right-click DualSense Wireless Controller → Configure speakers → Quadraphonic, then reload this page.
  8. No sound at all? In Windows, set the DualSense Wireless Controller speaker volume to 100%.
